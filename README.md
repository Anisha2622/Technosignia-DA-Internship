# TechnoSignia Data Analytics Internship

## About This Repository

Welcome to my Data Analytics Internship repository at TechnoSignia Software Training Institute.

This repository contains my daily internship tasks, practical exercises, assignments, sample datasets, Python programs, SQL queries, Excel practice files, Jupyter notebooks, and reports. I created this repository to document my learning journey and keep all my internship work organized in one place.

## Internship Objectives

- Understand the fundamentals of Data Analytics and Data Science.
- Learn Python programming for data analysis.
- Work with NumPy and Pandas.
- Practice SQL queries, joins, and aggregations.
- Learn data cleaning and exploratory data analysis (EDA).
- Create charts and visualizations using Matplotlib and Seaborn.
- Understand Excel, Power BI, and basic business metrics.
- Learn the fundamentals of Machine Learning.
- Understand Git and GitHub for version control and project sharing.
